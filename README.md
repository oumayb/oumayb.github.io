# oumayb.github.io

Source for my personal academic website: https://oumayb.github.io

This site is built on the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme by [Maruan Al-Shedivat](https://maruan.alshedivat.com), which is the main source of its code and design. I made only small changes to the layout, styling and content. al-folio is itself based on the [\*folio](https://github.com/bogoli/-folio) theme by [Lia Bogoev](http://liabogoev.com).

## Running locally

```bash
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000.
